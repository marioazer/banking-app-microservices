ARCHITECTURE AND TEXT WIREFRAMES
Standalone Angular components (no NgModules). Jasmine + Karma for unit
tests. Plain CSS (no Sass/Tailwind), per project instructions.

===============================================================================
COMPONENT TREE / FOLDER STRUCTURE
===============================================================================

frontend/src/app/
  core/
    auth.service.ts         login/verify-2fa/refresh/logout, holds access
                             token in memory (a signal), exposes isLoggedIn
    auth.guard.ts            functional route guard, uses auth.service
    jwt.interceptor.ts       functional HttpInterceptor, attaches
                             Authorization header, handles 401 -> refresh ->
                             retry-once -> logout-on-failure
    error.interceptor.ts     normalizes backend error bodies into a shared
                             shape the UI can render (incl. the KYC 403
                             special case for transfer endpoints)
    models/
      auth.models.ts         LoginRequest, LoginResponse, TwoFaRequest, etc.
      account.models.ts      AccountOverview, TransactionEntity, Page<T>
      profile.models.ts      ContactInfo, KycStatus, UserPreference
      transfer.models.ts     InternalTransferRequest, ExternalWireRequest,
                             TransferResponse
    services/
      account.service.ts     wraps GET /api/v1/accounts,
                             GET /api/v1/accounts/{id}/transactions
      profile.service.ts     wraps profile + preferences endpoints
      transfer.service.ts    wraps internal/external transfer endpoints

  shared/                    dumb, reusable, presentation-only components
    button/
    input/
    table/
    modal/
    alert-banner/            renders success/error/info messages, used for
                             the KYC-blocked and pending-review states

  features/
    signup/
      signup.component.ts/html/spec.ts             (added post-launch)
    login/
      login.component.ts/html/css/spec.ts
      two-factor.component.ts/html/css/spec.ts     (child step of login)
    dashboard/
      dashboard.component.ts/html/css/spec.ts
    account-transactions/
      account-transactions.component.ts/html/css/spec.ts
    transfer/
      transfer.component.ts/html/css/spec.ts        (tabbed container)
      internal-transfer-form.component.ts/html/css/spec.ts
      external-transfer-form.component.ts/html/css/spec.ts
    profile/
      profile.component.ts/html/css/spec.ts
    alert-preferences/
      alert-preferences.component.ts/html/css/spec.ts

  app.routes.ts               route table, authGuard applied to every route
                             except /login
  app.config.ts               providers: HttpClient with jwtInterceptor +
                             error.interceptor, router
